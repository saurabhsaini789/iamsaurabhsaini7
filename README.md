# Portfolio Website | Saurabh Saini

A modern, responsive portfolio website showcasing my work as an Instructional Designer, Learning Experience Designer, and Front-End Developer. Built with HTML, CSS, and JavaScript.

## 🌐 Live Site

Visit the live portfolio at: [iamsaurabhsaini.com](https://iamsaurabhsaini.com)

## ✨ Features

- **Responsive Design**: Fully responsive layout optimized for desktop, tablet, and mobile devices
- **Dark/Light Mode**: Toggle between dark and light themes with persistent user preference
- **Multi-page Portfolio**: Comprehensive sections including:
  - About & Services
  - Resume & Experience
  - Project Portfolio
  - Learning Hub
  - Blog
  - Contact Form
- **Interactive Components**: 
  - Testimonial carousel with detailed modal views
  - Client logo showcase
  - Floating call-to-action buttons
  - Smooth page navigation
- **SEO Optimized**: Includes meta tags, structured data (JSON-LD), and semantic HTML
- **Analytics Integration**: Google Analytics 4 and Microsoft Clarity tracking
- **Performance Focused**: Optimized images, lazy loading, and efficient CSS/JS

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structured content
- **CSS3**: Custom styling with CSS Grid, Flexbox, and CSS Variables
- **JavaScript (ES6+)**: Interactive functionality and theme management
- **Ionicons**: Icon library for UI elements
- **Google Fonts**: Poppins font family

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A web server (optional, for local development)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/your-repo-name.git
   cd your-repo-name
   ```

2. Open `index.html` in your browser, or use a local web server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

3. Navigate to `http://localhost:8000` in your browser

## 📝 Customization

### Updating Personal Information

- Edit `index.html` to update contact information, bio, and services
- Update structured data (JSON-LD) in the `<head>` section for SEO
- Modify social media links in the sidebar contacts section

### Changing Theme Colors

- Edit CSS custom properties in `assets/css/style.css`
- Look for `--orange-yellow-crayola` and other color variables

### Adding Projects

- Add project details in `portfolio.html`
- Include project images in `assets/projects/[project-name]/images/`
- Update project template if needed
